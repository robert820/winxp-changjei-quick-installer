## 📖 软件简介

在电脑打字黄金时代，**Windows XP 的“微软旧仓颉”与“旧速成（简易输入法）”** 凭借极速响应、零延迟、直观的选字排列与稳定的兼容性，成为无数打字爱好者与文字工作者不可取代的习惯手感。

然而，随着 Windows 系统不断演进，微软在现代控制台中隐藏了旧版输入法的安装路径，导致现代新版输入法在日常输入或各类软件中容易出现候选框隐形、卡顿等兼容性问题。

**「微软 Windows XP 旧仓颉与旧速成输入法安装与设置工具」** 是一款纯净绿色免安装实用工具，提供**一键安装**与**一键解除安装**，免除繁琐的手动设置，随时随地找回最流畅习惯的经典输入体验。

## 📦 下载与使用说明

### 📥 下载方式
1. 前往本项目的 [Releases 页面](https://github.com/robert820/winxp-changjei-quick-installer/releases) 下载最新版二进制可执行文件。
2. 本程序为**单文件免安装绿色执行档 (Portable Freeware)**，无需安装额外依赖库，下载即可放置于 U 盘随身携带。

### 🚀 使用指南
1. 下载后请**鼠标右键点击程序，选择“以管理员身份运行”**（安装系统全局输入法需要管理员权限）。
2. 在主界面中查看当前系统版本与输入法安装状态：
   - 点击 **“一键安装旧仓颉”** 或 **“一键安装旧速成”**（或 **“一键安装两者”**）。
   - 观察日志窗口显示“安装成功 ✓”即表示完成。
3. 按下键盘快捷键 `Ctrl + Shift` 或 `Win + Space`，即可切换使用经典旧仓颉/旧速成打字！
4. 若日后想移除，点击 **“解除安装”** 按钮即可干净卸载。
