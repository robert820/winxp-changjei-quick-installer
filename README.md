## 📖 軟體簡介

在電腦打字黃金時代，**Windows XP 的「微軟舊倉頡」與「舊速成（簡易輸入法）」** 憑藉極速響應、零延遲、直覺的選字排列與穩定的相容性，成為無數打字愛好者與文字工作者不可取代的習慣手感。

然而，隨著 Windows 系統不斷演進，微軟在現代控制台中隱藏了舊版輸入法的安裝路徑，導致現代新版輸入法在日常輸入或各類軟體中容易出現候選字框隱形、卡頓等相容性問題。

**「微軟 Windows XP 舊倉頡與舊速成輸入法安裝與設定工具」** 是一款純淨綠色免安裝實用工具，提供**一鍵安裝**與**一鍵解除安裝**，免除繁瑣的手動設定，隨時隨地找回最流暢習慣的經典輸入體驗。

## ✨ 核心功能

### 1. ⚡ 一鍵安裝 Windows XP 經典舊倉頡 / 舊速成（簡易）
提供獨立的「一鍵安裝舊倉頡」、「一鍵安裝舊速成」以及「一鍵安裝兩者」按鈕。點擊後系統全自動完成環境配置與鍵盤掛載，數秒內即可開始流暢打字。

### 2. 🛡️ 乾淨解除安裝與還原機制
安裝後若有需要，工具亦提供完整的卸載功能。自動清理殘留項目並重新整理輸入法服務，無損復原為乾淨狀態。

### 3. 📜 完整即時操作日誌與一鍵複製
所有安裝步驟與處理狀態均完整顯示於主畫面日誌區，並支援一鍵複製日誌內容，安裝過程透明安心。

## 📦 下載與使用說明

### 📥 下載方式
1. 前往本專案的 [Releases 頁面](https://github.com/robert820/winxp-changjei-quick-installer/releases) 下載最新版執行檔。
2. 本程式為**單一免安裝綠色執行檔 (Portable Freeware)**，無須安裝額外相依元件，下載即可隨身攜帶。

### 🚀 使用指南
1. 下載後請**滑鼠右鍵點擊執行檔，選擇「以系統管理員身分執行」**（配置全域系統輸入法需要系統權限）。
2. 在主畫面中檢視當前系統版本與輸入法安裝狀態：
   - 點擊 **「一鍵安裝舊倉頡」** 或 **「一鍵安裝舊速成」**（或 **「一鍵安裝兩者」**）。
   - 觀察日誌視窗顯示「安裝成功 ✓」即表示完成。
3. 按下鍵盤快捷鍵 `Ctrl + Shift` 或 `Win + Space`，即可切換使用經典舊倉頡/舊速成打字！
4. 若日後想移除，點擊 **「解除安裝」** 按鈕即可乾淨卸載。
